#  Python To-Do List Application

A lightweight, terminal-based To-Do List application written in pure Python. This program allows users to efficiently manage their daily tasks, mark completed items, save tasks locally, and maintain clean task organization without any external dependencies.

---

## Preview

![]

##  Features

-  **Add Tasks**: Easily append new tasks to your list.
-  **View Tasks**: Display all pending and completed tasks with clear visual status indicators.
-  **Mark Complete**: Mark tasks as finished without deleting them.
-  **Delete Tasks**: Remove individual tasks or clear your entire list.
-  **Data Persistence**: Automatically saves tasks to a local file (`tasks.json` or `tasks.txt`) so your progress is preserved across sessions.
-  **Zero Dependencies**: Runs entirely on the standard Python library.

---

##  Requirements

- **Python 3.6** or higher installed on your system.
